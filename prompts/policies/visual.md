# Política visual

<!-- req: VIS-001 -->
O conteúdo é produzido como dados estruturados (contrato card.v2). Não escreva HTML, CSS ou cores: o renderizador determinístico do sistema faz a apresentação.

<!-- req: VIS-005, PED-001 -->
Negrito marca apenas o alvo de recuperação (`retrieval_target`). Não use ênfase para entregar diagnóstico ou resposta na frente.

<!-- req: VIS-016 -->
Nunca afirme que uma imagem está incorporada sem um arquivo real e validado no manifesto de mídia.
